# V0.8.0 2v2 画面更新检查报告

日期：2026-09-25

## 改动

- 本轮追加天空与光照修订：渐变天空、程序化云层、太阳与光晕；暖色方向光、天空/地面环境光和更自然的远景雾色。

- HUD 分队面板、目标门牌、计分和中央倒计时重新排版；加入紧急倒计时、受击和起火提示动画，并为窄屏提供布局断点。
- 两队车辆新增悬浮队色标识，炮弹使用球队色彩包装；被命中时短暂显示冲击闪光。

## 检查

- `build.py` 生成候选时检查 173 个唯一 DOM ID、直接 DOM 引用和所有内联 JavaScript 语法，通过。
- 本地 Chromium 检查多人菜单的合作/2v2 模式选择与四人限制，画面显示正常。
- 本地桌面 Chromium 截图确认天空渐变、云层和太阳光晕正常显示；菜单与城市远景正常绘制。
- 视觉修订后的候选 HTML 与根目录 index 均由构建器重新生成；ZIP 重新打包自同一候选 HTML。
- Worker JavaScript 语法检查与 `git diff --check` 通过。

## 边界

没有实际 2v2 四人联机对局，因此 HUD/车队旗标/炮弹效果未在真实比赛场景验收；没有手机实机截图或 400ms 延迟模拟结果。真实 WebRTC/TURN 与 gameplay 回归仍需另行验收。

本轮没有进行手机实机帧率测量；天空 shader 的移动设备性能尚未量化。Chromium 画面预览不替代 iPhone/Android 实机检查。
