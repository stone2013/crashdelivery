# V0.7.4 THREE PLAYER CO-OP — 实现与测试报告

日期：2026-09-24
基线：本地 `main` 与 GitHub `main` 同为 `767d424`（V0.7.3.1）；根目录 `index.html` 保留为原版参考。

## 本版本改动

- 房间人数扩展到三名玩家：一名房主与最多两名客机。三名玩家各有独立人物、岗位、输入/动作序号与客户端状态；车辆、碰撞、NPC 交通、包裹和订单仍由房主权威模拟。
- 新增游戏内玩家管理面板：三人名额、昵称、驾驶/投递岗位、在线/断线、P2P/TURN、RTT、邀请复制；房主可移除客机。
- 玩家列表只有状态变化时才重绘，避免每个世界快照重建节点造成“移出”按钮无法稳定点击。
- 断线槽位保留 20 秒支持自动重连；满员时拒绝新客机；被房主移出的客户端不能在该房间重入。
- 保留本地驾驶预测、房主权威模拟、P2P 优先、Cloudflare TURN fallback 与 V0.7.2 六路 relay 诊断。多人协议升至 `crash-delivery-mp074-1`。

## 检查结果

- 构建通过：HTML 318,799 字节、157 个唯一 DOM ID、所有直接 DOM 引用存在；Node.js inline JavaScript 语法检查通过。
- 三客户端 Chromium 回归通过 **11/11**：桌面房主、手机竖屏客机、桌面横屏客机。覆盖三槽名册、玩家管理、三人权威人物快照、驾驶位互斥、房主移人、单人入口、18 单/城市数据、手机面板布局与运行时错误。使用确定性 in-page 消息桥，不模拟公网时延，也不代表真实 WebRTC 连通性。
- 六路 ICE 诊断模拟通过 **9/9**：六条 URL 独立 relay-only PeerConnection、真实 gathering 调用顺序、只认 relay、超时、最快路线保存、临时凭证不进入 UI/localStorage。该用例使用合成凭证及候选，不代表 Cloudflare 实际分配成功。
- 未执行真实 PeerJS 信令房间、Cloudflare TURN allocation、完整历史玩法回归或 Wi-Fi↔5G 异网验收；不据此声称公网验收通过。
- 未改动 Worker、根 `index.html` 或任何 Cloudflare Secret；未把临时 TURN 凭证写入源码、报告、存储或 Git。
