## Limits

No new real-world P2P/TURN game session or cross-network four-player acceptance run was performed. `native_ice_candidates_verified`, `internet_webrtc_verified`, and `turn_relay_verified` remain false in `VERSION.json`.

The public room directory uses Workers KV. Its cross-location reads are eventually consistent and can lag a write; the lobby refreshes the list every 20 seconds. Room-code joining remains available during list propagation. See [Cloudflare Workers KV consistency](https://developers.cloudflare.com/kv/concepts/how-kv-works/).
