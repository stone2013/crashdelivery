# V0.8.0 2v2 对抗候选更新

## 视觉修订：天空与光照

- 3D 场景天空增加由蓝色天顶过渡到浅色地平线的渐变、轻薄程序化云层、太阳圆盘与柔和光晕。
- 地面/车辆/建筑使用暖色方向光和半球环境光，增强明暗层次；远景雾色与天空地平线衔接，雾化过渡更自然。
- 角色预览保持原有暗色舞台，不受游戏天空背景影响。
- 桌面 Chromium 主菜单场景截图已检查；未做手机实机帧率及完整比赛验收。

- 修复 2v2 运行时代码作用域，确保模式选择器与对战逻辑能从游戏主脚本访问内部多人函数。
- 对战 HUD 改为分队记分牌：橙/蓝队独立分数、下一目标门牌、中央倒计时与加时标记；受损状态和维修按钮单独成行，手机窄屏自动压缩。
- 加入最后 30 秒倒计时提示、车辆受击闪屏、起火/瘫痪状态脉冲提示。
- 两辆车增加浮动队色旗标，炮弹使用对应队伍色彩的快递包装，便于追踪对战双方。
- 多人大厅显示“车队合作 / 2v2 对抗”；选择 2v2 后固定四人房。
- 保持房主权威的送货计分、命中、车辆状态和维修；TURN 临时凭证不写入候选页面。

## 检查范围

本地桌面 Chromium 已确认多人菜单的模式入口与 2v2 四人限制。构建器检查通过。没有四客户端完整比赛或手机实机视觉验收。
