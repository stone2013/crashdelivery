# V0.8.0 2v2 对抗候选更新

- 多人大厅增加“车队合作 / 2v2 对抗”选择；对抗房间固定四人，并使用独立房间命名空间。
- 对抗房间加入邀请链接模式参数；公开房间列表显示模式并在加入前切换到对应模式。Cloudflare Worker 房间目录接受 `gameMode`，2v2 条目必须为四人房。
- 对局包含两队送货计分、五分钟比赛与平分后 60 秒突然死亡加时；对战 HUD 显示分数、目标门牌、剩余时间及本队车辆状态。
- 副手可以拉杆发射普通快递。弹道会按对方车辆速度预判；房主权威结算命中、减速、累计火灾、灭火与维修。三次命中瘫痪起火，累计燃烧 30 秒爆炸判负。
- 客机司机保持本地即时驾驶响应；权威快照按误差与 RTT 平滑收敛，受击、瘫痪、起火或爆炸时硬校正。
- 显示第二辆车、货物和车厢工具；隐藏合作订单/金额操作，固定司机和副手岗位。
- TURN 临时凭证仍只由现有 Worker 在联机时提供，候选页面不包含凭证或 Secret。

## 当前边界

这是独立候选包，不替换当前发布的 `index.html`。已通过构建器的内联 JavaScript 语法、DOM ID 与直接引用检查，以及 Worker JavaScript 语法检查。四客户端 Chromium、实际 WebRTC/TURN、碰撞与城市交通交互尚未验收；请勿将该候选视为线上已发布版本。
