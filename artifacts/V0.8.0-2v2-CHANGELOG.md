# V0.8.0 2v2 对抗候选更新

- 修复 2v2 运行时代码作用域：将规则与对战适配器构建到游戏主脚本作用域内。此前被拼接到页面外层脚本时，因访问不到 `roomId` 等游戏内部函数而在启动时报错，模式选择器因此没有渲染。
- 本地 Chromium 确认多人菜单可见“车队合作 / 2v2 对抗”；选择 2v2 后固定四人上限。
- 多人大厅显示“车队合作 / 2v2 对抗”选项；对抗房间固定四人，并使用独立房间命名空间。
- 对抗房间邀请链接包含模式参数；公开房间列表显示模式并在加入前切换到对应模式。Cloudflare Worker 房间目录接受 `gameMode`，2v2 条目必须为四人房。
- 对局包含两队送货计分、五分钟比赛与平分后 60 秒突然死亡加时；HUD 显示分数、目标门牌、剩余时间及本队车辆状态。
- 副手可以拉杆发射普通快递。弹道按对方车辆移动预判；房主权威结算命中、减速、累计火灾、灭火与维修。三次命中瘫痪起火，累计燃烧 30 秒爆炸判负。
- 客机司机保持本地即时驾驶响应；权威快照按误差与 RTT 平滑收敛，受击、瘫痪、起火或爆炸时硬校正。
- 根目录 `index.html` 与独立候选 HTML 同步更新。TURN 临时凭证仍只由现有 Worker 在联机时提供，页面不包含凭证或 Secret。

## 当前边界

已确认本地 Chromium 多人菜单显示模式选择器，选择 2v2 后人数控件固定为四人。完整四客户端联机、实际 WebRTC/TURN、碰撞与城市交通交互尚未验收。
