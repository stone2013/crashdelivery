# 暴力快递 V0.9 · SKYWAY

**立体路网试验区 / 第一阶段可玩构建**

此包以已经核对过的 GitHub `stone2013/crashdelivery` V0.8.x + PWA 主线为基线，不是 V0.5。原首页为 386,253 字节，Git blob `8878517981cf87128ec73ecf36e0271f1b50896e`。旧首页标题仍写 V0.7.5，但实际包含 V0.8.0 2v2 runtime；本版保留该实现，并将首页与联机协议统一标记为 V0.9。

## 开始体验

解压后直接打开根目录 `index.html`，可以启动单人游戏和路网试跑。GLB 网格与颜色图已嵌入 HTML，不需要联网下载道路、引擎或模型。更推荐 Windows 运行 `Start_Windows.cmd`，用 localhost 启动；这个可选启动器需要 Python 3。游戏部署后运行不需要 Python、Node 或 npm。

首页新增 **“立体路网试跑”**，进入后一车 18 件货物不变。先向北走到弯角，再右转上坡；按 1–6 检查点依次体验：

1. 西侧上坡匝道。
2. +8 米高架桥面。
3. 东侧下降坡道。
4. 环岛南侧，顺时针绕行。
5. 同一座桥的地面层通道。
6. 北侧终点停靠；需要真正减速停稳。

试跑有独立计时，不给原城市订单伪造投递、不消费已送进度。J / “导览”打开试验区地图；金色是高架，灰蓝色是地面。地图不会暂停世界，放着砖时车仍会继续走。

**“原城市 · 单人派送”**保留旧城 18 单。旧城东侧 (112,56) 与新路网入口相接，也可以实际开过去。暂停菜单可以打开路网导览；其中“返回原城市”保留订单和包裹。

## 控制

电脑：WASD 驾驶/步行；B 放砖；V 离开驾驶位、在后门处上下车；E 交互；G 后门；F 辅助瞄准；Q 或鼠标左键蓄力投掷；空格跳跃；R 放下；M 订单；N 原城市地图；J 新路网导览；Esc 暂停。手机沿用情境按钮与摇杆，推荐先横屏试驾。

## 本版确实新增了什么

- 从用户提供的 Kenney City Kit Roads 2.1 选择 20 个原始 GLB；包含坡道、桥、环岛、直路、弯路、T 字路口、十字路口、斑马线、护栏、桥墩、路灯、路牌和施工道具。
- 共 88 个摆放实例，约 12,584 个三角形，合并为 20 个道路静态空间批次。原城市有自己的批次，不包含在此数字里。
- +8 米桥面与地面通道分层；坡道高度来自同一份可见三角网格，不是隐形平桥。车辆会俯仰；行驶中的货箱局部坐标也采用倾斜变换。
- 包裹会落到桥面上或桥下，不能从下方穿过跨越段桥面；地面玩家不会被上层车辆的平面碰撞框挡住。
- 25 个试验区节点、52 条有向连接。高架上下两个同坐标节点是不同节点，寻路必须经匝道绕行。
- 5 辆试验区 NPC 使用既定高架/地面回路，会跟车、在试验路口等灯；同高度才互相阻挡。原城 14 辆 NPC 不变。
- 合作模式同步桥面高度、坡度、试跑进度和新 NPC。房主可通过导览转移整车，客机不能擅自传送；车外队友须先上车，驾驶位不能被强占。

## 明确边界

这是“先接 15–20 个模块、验证立体驾驶”的第一阶段，不是把整座旧城全部换成 Kenney，也没有新建 18 个桥上配送地址。

原 2v2 规则和四人大厅保留，**2v2 仍使用原城市**，新路网在该模式下不启用；不要把这一版当作已完成高架 2v2 对战地图。试验区车辆遭撞后停车，9 秒恢复，不套用原城区的爆炸/拖车清障系统。沿坡道的货箱物理、护栏和车体碰撞是轻量街机近似，不是轮胎悬挂/完整刚体仿真。路灯/路牌等小道具主要用于视觉。

原 TURN / PeerJS / Worker 没有替换。双方需要运行 V0.9 同一构建，不能与旧版房间混连。**没有声称本次已经验证互联网 TURN、Safari 真机、手机实测 FPS 或完整 2v2 对局。** 具体已测试与未测试项目见 `TEST_REPORT.md`。

## PWA 与部署

网页可安装配置、192/512 PNG 和 Apple Touch Icon 保留。部署需把根目录 `index.html`、`sw.js`、`manifest.webmanifest`、`icons/`、`.nojekyll` 一起发布在同一目录。可放网站根路径，也可放项目子目录。

首次联网打开并完成缓存后，Service Worker 设计为断网时回退到缓存的完整单人游戏。多人、房间目录、TURN 凭证永远需要网络，不进入离线缓存。HTML 网络优先；新 Service Worker 等用户主动确认更新，不在联机中途强制刷新；只清理本应用同 scope 的旧缓存，不删除别的游戏缓存。

iPhone 通过 Safari 分享菜单添加到主屏幕；Chrome/Edge 通过浏览器安装入口。这里的安装与离线重启尚未做硬件验收。直接用 `file://` 打开可以单人试玩，但不会启用 Service Worker。

现有 API 仍为 `https://api.feelpal.app/turn-credentials`。使用原 `game.feelpal.app` 部署时沿用原设置；换新域名或 localhost 测联机时，Worker 的允许来源必须匹配新来源。不要把 API Token、TURN 长期密钥、临时 credential 放进代码或静态托管。

**本次只生成 ZIP，没有推送 GitHub，也没有修改 Cloudflare 配置。** 上传前先备份当前线上版本。

## 源码与重建

```
python build.py
```

构建脚本会先校验 `src/v08-baseline.html` 的 SHA-256，拒绝从其他版本重建；再接入 `src/roads-v09.js`、`src/roads-v09.css`、PWA 脚本和 20 个原始 GLB，生成根目录 `index.html`、版本文件与按内容哈希更新的 `sw.js`。有 Node 时运行内联脚本语法检查。不要再运行旧仓库的 `source/` 来生成此版本。

原始资产及共享色图在 `assets/kenney-roads/`，用于编辑、审查和重新构建。当前渲染器保留 PocketGL：浏览器启动时真实解析 GLB，按 UV 采样共享调色板并烘焙为顶点色，未迁移 Three.js。仅针对这批 TRIANGLES / identity-node 模型；不是通用 glTF 动画、压缩模型加载器。
