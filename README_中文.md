# 暴力快递 V0.5 ONLINE

基于正式联机 V0.2.1 的双人房间系统升级。

- 双人同车：房主默认驾驶，队友默认货箱投递
- 6 位房间码 + PeerJS/WebRTC
- 六类包裹：普通、重箱、小包、易碎、圆筒、神秘
- 包裹完整度、货损、BANK SHOT / LONG SHOT / 高速投递 / EXPLOSIVE DELIVERY
- 永久车库升级：发动机、刹车、抓地力、货箱防滑
- 砖压油门、实体后门、掉货、第一人称货箱、小车起火爆炸继续保留

联机时世界状态由房主权威计算；双方必须使用 V0.5 ONLINE。房间连接需要联网加载 PeerJS，并依赖 WebRTC 网络连通性。
