## 仍未验证的边界

以下内容**没有**被当前环境证明通过：

1. iPhone 蜂窝网络 ↔ Mac / Windows Wi-Fi 的真实异网 PeerJS 房间。
2. 中国大陆 ↔ 海外的 NAT / 防火墙组合。
3. 有效生产 TURN 凭据产生 `relay` candidate。
4. 真实网络丢包、网络切换（Wi-Fi→5G）后的恢复。
5. Safari 真机的 `getStats()` selected candidate pair 展示。

因此 V0.7.1 的含义是：**已经实现公网所需的 STUN/TURN 配置、诊断、relay 策略和重连机制，但仍需用真实 TURN + 两个异网设备完成最终验收。**

## 真实 TURN 验收方法

1. 两台设备部署同一 V0.7.1。
2. 在双方“网络设置”填入同一套有效 TURN。
3. 运行 ICE 自检，双方都应看到 `relay`。
4. 将连接策略改为“强制 TURN 中继”。
5. 一台使用 Wi-Fi，另一台关闭 Wi-Fi 使用蜂窝数据。
6. 创建 / 加入房间。房间 HUD 应显示 `TURN 中继` 和 RTT。
7. 驾驶、开门、拿指定包裹、投递一次，再主动断网 3–5 秒后恢复，观察自动重连。
